# Firewall (UFW)

## Estado inicial
UFW ativo

## Regras aplicadas
- SSH permitido (porta 22)
- HTTP permitido (porta 80)

## Comandos utilizados
- ufw allow ssh
- ufw allow http
- ufw enable

## Estado final
Firewall ativo e a proteger o servidor

## Validação
O WordPress continua acessível após ativação do firewall
