Bem-vindo ao nosso projeto

Este site foi desenvolvido no âmbito da unidade curricular Linux, Segurança e Cloud com o objetivo de demonstrar a publicação de um serviço web utilizando o servidor Nginx num ambiente Linux.

O projeto aborda conceitos fundamentais como instalação de serviços, gestão de ficheiros, permissões, publicação de conteúdo web e validação de serviços.

Objetivos do Projeto

  • Publicar um serviço web funcional.
  • Utilizar o servidor Nginx.
  • Aplicar boas práticas de administração Linux.
  • Validar o funcionamento do serviço.
  • Documentar todo o processo técnico.
