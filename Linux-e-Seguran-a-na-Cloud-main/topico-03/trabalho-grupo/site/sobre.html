Sobre o Projeto

Início Sobre

Descrição

Este projeto consiste na criação e publicação de um pequeno site institucional utilizando HTML, CSS e o servidor web Nginx.

Tecnologias Utilizadas

  • Linux Ubuntu Server
  • Nginx
  • HTML5
  • CSS3
  • Git e GitHub

Arquitetura

O navegador envia pedidos HTTP para a porta 80 do servidor. O Nginx recebe esses pedidos e disponibiliza os ficheiros armazenados no diretório de publicação.
